# RUANG — Interior Design Studio

Website konsep studio interior, dibuat dengan HTML, CSS, dan JavaScript murni.

## File
- `index.html`: konten dan struktur website
- `style.css`: desain responsif
- `script.js`: navigasi mobile, filter proyek, dan formulir konsultasi demo
- `DOKUMENTASI_TUGAS.md`: kerangka dokumentasi untuk tugas

## Menjalankan website
1. Ekstrak ZIP.
2. Buka folder ini menggunakan Visual Studio Code.
3. Buka `index.html` di browser atau jalankan melalui ekstensi Live Server.
4. Koneksi internet dibutuhkan untuk memuat foto dari Unsplash dan Google Fonts.

## Catatan penting sebelum publikasi
- Website ini adalah konsep/demo brand fiktif RUANG, bukan studio interior sungguhan.
- Nama proyek dan gambar adalah contoh inspirasi visual. Jangan menyajikannya sebagai proyek klien nyata.
- Formulir hanya menyiapkan draft email. Alamat `hello@ruangstudio.example` adalah placeholder yang tidak aktif; ganti dengan email yang benar sebelum demo atau jelaskan bahwa formulir adalah simulasi.
- Pastikan seluruh foto termuat dengan baik. Foto diambil dari URL gambar Unsplash dan memerlukan internet.
- Ubah konten dan detail yang diperlukan sebelum dikumpulkan.
